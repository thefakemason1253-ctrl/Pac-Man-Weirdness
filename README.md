# Maze Muncher (work-in-progress)

A small maze-chase arcade game inspired by classic arcade titles. This project is a hobby remake / learning project and is not affiliated with or endorsed by the owners of Pac‑Man.

Important: Pac‑Man and related characters are trademarks of their respective owners. This repository contains original code and assets created for learning and entertainment purposes only — do not include or redistribute trademarked assets (sprites, sound effects, logos) owned by others.

## Demo
A mobile-friendly HTML demo has been added on the `mobile-demo` branch.

Try it locally:

1. git fetch origin
2. git checkout mobile-demo
3. Open `index.html` in a browser, or run a local server:
   - python3 -m http.server 8000
   - Visit http://localhost:8000/index.html

## Features
- Classic maze-chase gameplay: move a character through a maze, collect pellets, avoid enemies.
- Mobile-first controls (touch buttons) and keyboard support.
- Score, lives, and simple enemy AI.

## Controls
- Arrow keys or WASD to move.
- On-screen touch buttons for mobile: ▲ ◀ ▼ ▶
- P or Space to pause.

## How to run
(Engine-agnostic demo instructions)
